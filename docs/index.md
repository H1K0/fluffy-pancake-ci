# fluffy-pancake

Консольный TODO-менеджер на Python.

## Запуск

```
python main.py
```

## Устройство проекта

| Модуль       | Назначение                                  |
| ------------ | ------------------------------------------- |
| `main.py`    | меню и ввод-вывод в консоли                 |
| `logic.py`   | операции над задачами (добавить, отметить…) |
| `storage.py` | чтение и запись задач в `tasks.json`        |
| `utils.py`   | вспомогательные функции                     |

Подробности по каждой функции: [Справочник API](api.md).
